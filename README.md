# الرفيق — أذكار المسلم (Al-Rafeeq)

تطبيق ويب تقدّمي (PWA) يعمل على الموبايل وبدون إنترنت بعد أول فتح.

تم تصميم وتطوير التطبيق بواسطة **Mohamed Eldawly**.

## ما في الإصدار 1.0.0
- أذكار الصباح والمساء بالعداد، تنتقل تلقائيًّا للذكر التالي، مع الفضل والمصدر وحفظ الموضع.
- الورد اليومي: 17 ذكرًا (استغفار، تسبيح، تحميد، تهليل، حوقلة، صلاة على النبي ﷺ، الصلاة الإبراهيمية…) مع سبحة 33 حبّة وأوسمة عند 100 و200 و300 و500 و1000 وهدف يومي.
- المصحف الشريف: نص وخط مجمع الملك فهد (رواية حفص، الإصدار 18) بترقيم صفحات مصحف المدينة (604 صفحة)، تقليب بالسحب، فهرس السور والأجزاء، بحث، علامات، وحفظ آخر صفحة.
- مواقيت الصلاة: محافظات مصر الـ27 ومدن عربية أو حسب موقعك، بطرق الحساب الرسمية (مكتبة adhan).
- خمسة ثيمات، أصوات هادئة مولّدة برمجيًّا يمكن إيقافها، اهتزاز، تذكير بالأذكار، مقدمة متحركة، ورقم إصدار مع زر البحث عن تحديثات.

## البنية
```
src/
  config.js          اسم التطبيق والمطور ورقم الإصدار (يُقرأ من release.json)
  themes.js          الثيمات الخمسة كمتغيّرات CSS
  store.js           الحالة المحفوظة على الجهاز (zustand + رقم مخطط للترقية)
  router.js          توجيه بالـ hash
  data/              الأذكار، الورد، المدن، بيانات المصحف المولّدة
  lib/               الصوت، الصلاة، المصحف، التحديث، الإشعارات، الأرقام العربية
  components/        المقدمة، شريط التنقل، عناصر الواجهة
  screens/           الشاشات
scripts/build-data.mjs   يحوّل بيانات المجمع إلى ملفات التطبيق
release.json            رقم الإصدار وملاحظاته (يظهر في الإعدادات عند وجود تحديث)
```

## التشغيل والبناء
```bash
npm install
npm run dev      # تشغيل محلي
npm run build    # البناء في dist/ (يولّد version.json و sw.js تلقائيًّا)
```

## إصدار تحديث
1. عدّل `release.json`: ارفع `version` (مثلًا 1.1.0) واكتب الملاحظات.
2. ادفع التغييرات إلى `main` — ملف GitHub Actions يبني وينشر على GitHub Pages.
3. يظهر للمستخدم «يتوفر إصدار جديد» من الإعدادات ← البحث عن تحديثات.
